This is a React component library that includes these types of components:

1. **Layout Components**: Components that take in any JSX and other components and puts them together into0 some sort of layout (e.g One Columm, Card Grid, Bento Grid, etc.).
2. **UI Components**: Your typical components like a multi-select dropdown menu, but I took a different approach than other React component libraries when creating them.
